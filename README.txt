This folder contains several critical files to properly use the rapid design tool

Mech Generator Student.manifest		 this file is used by fusion to identify the script that will run. 
	
Mech Generator Student.py		     this file tells fusion what to do.

4BARMECH.json						 Example data file to build a 4 bar mechanism

6BARMECH_WATT_I.json				 Example data file to build a Watt-I mechanism

6BARMECH_STEPHENSON_II.json			 Example data file to build a Stephenson-II mechanism

base.json							 This file shows the layout of the json file. Json files do not normally support comments, so this file cannot actually be run.
